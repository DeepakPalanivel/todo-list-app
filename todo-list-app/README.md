# To-Do List Web App

A beginner-friendly task manager built with HTML, CSS, and vanilla JavaScript.

## Features
- Add tasks
- Mark tasks complete
- Edit tasks
- Delete tasks
- Save tasks in browser localStorage
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in your web browser. No installation or build step is required.

## Deploy to Vercel
1. Upload `index.html`, `style.css`, and `script.js` to the root of a GitHub repository.
2. Import the repository in Vercel.
3. Choose **Other** as the framework preset.
4. Leave Build Command and Output Directory blank.
5. Deploy.

Tasks are saved in the current browser only; localStorage does not sync between devices.
